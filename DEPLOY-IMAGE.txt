CR Docs 镜像模式部署（部署机全程不构建）
============================================
前置：部署机装好 Docker Engine + docker compose v2 插件。

在本目录执行：
  1) docker load < cr-docs-image.tar.gz     # 导入镜像（tag: zenmux-docs-web:latest）
  2) ./deploy.sh --image                     # 不构建，直接起：migrate + next start + seed
     # 指定对外端口： WEB_PORT=80 ./deploy.sh --image
     # 不灌示例内容： ./deploy.sh --image --no-seed

内存护栏已内置：web 512m / db 256m（与 console-v2 同机时保护邻居）。
起来后：
  前台 http://<机器IP>:<端口>/docs/zh    后台 http://<机器IP>:<端口>/admin
  初始管理员见 .env（SEED_ADMIN_EMAIL / SEED_ADMIN_PASSWORD，登录后请改密码）

日志：docker compose logs -f web   停止：docker compose down   （数据保留在卷 cr-docs_pgdata）
